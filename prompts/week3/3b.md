# 2. 3B-1 — Correspondence attribution

## Phase 3A trigger

Phase 3A compared:

    A:
        SIFT features
        +
        SIFT brute-force matching

against:

    B:
        ALIKED_N32 features
        +
        ALIKED LightGlue matching

B did NOT improve registration.

However B increased mean track length on every clip by approximately:

    +17% to +75%

while usually producing fewer points and costing substantially more.

This establishes a correspondence-quality effect, but A→B changes TWO things
simultaneously:

    feature representation
    +
    matcher

Therefore Phase 3A cannot attribute the track-length gain to ALIKED, LightGlue,
or their interaction.

## Question

What component actually produces the longer tracks?

And do longer tracks translate into materially better triangulation / shape
conditioning?

## First experiment — clean 2×2 factorial

Use only interfaces already exposed by the installed COLMAP binary.

Construct:

    F1:
        SIFT
        +
        SIFT_BRUTEFORCE
        = existing A

    F2:
        SIFT
        +
        SIFT_LIGHTGLUE

    F3:
        ALIKED_N32
        +
        ALIKED_BRUTEFORCE

    F4:
        ALIKED_N32
        +
        ALIKED_LIGHTGLUE
        = existing B

This isolates:

    F1 → F2
        matcher effect with SIFT features fixed

    F3 → F4
        matcher effect with ALIKED features fixed

and gives a cleaner interpretation of the existing A→B difference.

## Clips

Primary:

    wreck_05

Secondary:

    wreck_01

Control only if required:

    wreck_07

Do NOT run all six clips unless an unexpected result genuinely requires it.

## Measurements

Record:

- registered frames;
- submodel sizes;
- number of 3D points;
- observations/image;
- mean track length;
- median track length;
- track-length distribution;
- feature count;
- verified match count;
- inlier ratio if available;
- triangulation-angle distribution;
- baseline/depth conditioning proxy;
- long-baseline track survival;
- scale-aligned sparse shape at co-visible image observations;
- range-dependent residual;
- radius-dependent residual;
- repeatability;
- runtime.

Reprojection error is diagnostic only.

## Interpretation

Longer tracks alone do NOT establish better geometry.

The important question is:

    Does the matcher/feature change improve triangulation conditioning or
    materially alter the recovered scene shape?

If shape remains essentially the same after one clip-level scale, classify the
track improvement as useful-but-not-architecture-changing.

# 5. 3B-4 — Temporal-baseline / triangulation sensitivity

## Why this experiment exists

Successful registration does NOT establish well-conditioned triangulation.

Video can contain many highly redundant frames with tiny baselines.

Phase 3A used 48 frames over a fixed clip interval.

Test whether the classical reconstruction changes materially when those 48
observations are replaced by fewer views spanning the SAME temporal extent.

This directly tests the weak-parallax / redundant-frame hypothesis without
introducing a new method.

## Primary clips

    wreck_05
    wreck_01

Optional:

    cenote_01

because its source is 59.94 fps and the 48-frame sample spans only about six
seconds.

## Frame schedules

Use nested deterministic schedules spanning the same endpoints, approximately:

    48 frames
    24 frames
    12 frames

Do not choose favorable frames manually.

Preserve temporal extent.

Preserve endpoints where practical.

Use deterministic uniform subsampling.

## Method

Use ordinary configuration A:

    SIFT
    +
    brute-force
    +
    incremental COLMAP

Do not change feature parameters simultaneously.

## Measure

- registration fraction;
- track length;
- temporal span per track;
- triangulation angles;
- baseline/depth proxies;
- focal estimate;
- distortion estimate;
- point count;
- model fragmentation;
- repeatability;
- scale-aligned shape at observations shared between schedules;
- residual versus range;
- residual versus radius.

## Interpretation

Possible outcomes:

### Stable across schedules

Then weak temporal baseline is unlikely to explain the large Phase 3A shape
disagreement.

### Geometry changes materially / improves with fewer wider-spaced frames

Then original video sampling plausibly contributes to conditioning error.

### Geometry becomes worse with fewer frames

Then dense temporal overlap is helping despite small neighboring baselines.

Do not infer correctness from any schedule without C2.
